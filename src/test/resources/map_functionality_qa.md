# Чек-лист тестирования картографического приложения

## 1. Общая функциональность карты

- Проверить загрузку главной страницы и отображение карты
- Проверить масштабирование карты
- Проверить перемещение карты
- Проверить отображение и открытие событий на карте
- Проверить отображение туристических маршрутов на карте
- Проверить выбор даты и обновление данных

## 2. Подложка и темы

- Проверить переключение подложки после включения светлой темы
- Проверить доступность картографических подложек (более двух)

## 3. Построение маршрута и поиск

- Проверить построение маршрута и вычисление расстояния маршрута
- Проверить результат поиска определённого адреса и переход на его координаты

## 4. Контекстное меню

- Проверить контекстное меню / "Что здесь?"
- Проверить контекстное меню / импорт области
- Проверить контекстное меню / скопировать координаты, вставка их в поле поиска и проверка перехода в нужную точку
